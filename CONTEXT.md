# Evergreeners

Evergreeners is a developer consistency platform and digital garden that tracks coding habits, contributions, and streaks over time.

## Language

### Consistency & Identity

**Gardener**:
A registered developer on Evergreeners cultivating their coding habits and contribution record.
_Avoid_: User, client, account, customer

**Garden**:
The visual representation of a Gardener's contribution history and consistency over time.
_Avoid_: Profile graph, contribution grid, activity chart

**Streak**:
The count of consecutive active coding days maintained by a Gardener.
_Avoid_: Chain, momentum count, consecutive days

**Contribution Heatmap**:
A GitHub-style calendar matrix displaying daily commit volume and activity density.
_Avoid_: Activity map, commit chart, commit matrix

**Daily Digest**:
A scheduled daily summary delivering streak updates and momentum metrics to a Gardener.
_Avoid_: Daily email, notification roundup, status report

### Intelligence & Tracking

**The Eye**:
An intelligence watchlist tool enabling Gardeners to follow other public developers, observe activity momentum, and compare commit velocity.
_Avoid_: Spy tool, stalker mode, user tracker, watchlist

**Velocity**:
The rate of commit and pull request contributions by a developer over rolling 7-day and 30-day windows.
_Avoid_: Speed, activity rate, commit tempo

**Insight**:
An AI-generated analysis of a developer's consistency trends and commit velocity generated within The Eye.
_Avoid_: Summary, evaluation, AI critique

### Academy & Progression

**Academy**:
A structured developer education portal offering Git workflows, hands-on labs, and open-source contribution training.
_Avoid_: Course, school, tutorial portal

**Profile Audit**:
An automated diagnostic evaluating a developer's public GitHub presence across README quality, pinned repositories, and active projects.
_Avoid_: Account scan, profile check, code review

**Graveyard Index**:
A quantitative score reflecting the proportion of abandoned or stagnant repositories on a developer's GitHub profile.
_Avoid_: Dead repo score, inactive index, stale factor

**Capstone PR**:
The capstone pull request submitted by an Academy student demonstrating mastery of Git workflows for AI evaluation and certification.
_Avoid_: Final exam, capstone project, graduation test

**Certificate**:
A cryptographically verifiable credential identifier (`certId`) awarded upon graduating the Academy.
_Avoid_: Diploma, badge cert, completion token

### Challenges & Community

**Quest**:
A hands-on coding challenge or curated open-source repository issue that Gardeners fork, solve, and complete for points.
_Avoid_: Task, mission, ticket, exercise

**Goal**:
A Gardener-defined target for contribution volume or streak length within a specified timeframe.
_Avoid_: Objective, KPI, target metric

**Badge**:
An earned visual achievement recognizing consistency milestones, streak resilience, or Academy completion.
_Avoid_: Trophy, medal, sticker, reward

**Community Story**:
A verified Gardener testimonial and milestone narrative spotlighted in the community showcase.
_Avoid_: Review, comment, post, testimonial
